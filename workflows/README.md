# Workflows

The worker downloads the current official Comfy-Org MiniMax H3 UI templates to `/runpod-volume/workflows`.

RunPod worker-comfyui expects **API-format** workflow JSON in requests.
For the first live test, open the official H3 R2V template in a current local ComfyUI and use:

`Workflow -> Export (API)`

Do not hand-convert the workflow while H3 support is still changing.
